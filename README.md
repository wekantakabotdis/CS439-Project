# CS439-Project

Starter project for predicting ATP tennis match outcomes.

## Current Starter Work

The first notebook is:

- `notebooks/01_data_import_and_cleaning.ipynb`

It downloads Jeff Sackmann ATP match CSV files, combines them, does basic cleaning, and creates a few starter features:

- ranking difference
- ranking points difference
- age difference
- whether the higher-ranked player won

Processed CSV files are saved in `data/processed/`.

## Setup

Install the required Python packages:

```bash
pip install -r requirements.txt
```

Then open and run the notebook.
